自动读取每篇文献在 alphaXiv 上的点赞数与引用数，并把结果写入条目的 Extra 字段。 AlphaLikes 会从链接、DOI 或 Extra 字段里读取 arXiv 记录；条目里没有时，可以通过学术 API 自动查找。 点赞数在列里的显示方式；颜色由下面的「颜色」一节决定。 可以使用任意 CSS 颜色：#1a7f37、green、rgb(26 127 55)。分位数模式按当前列表里的点赞数排名，样本太少时自动退回固定阈值。 每次刷新会把当天的点赞数记入条目的 Extra 字段，列里就能显示「2979 ↑12」。 引用数据来自 Semantic Scholar 与 OpenAlex。被引次数变化很慢，所以缓存时间比点赞数长。 Google Scholar 没有公开 API，插件读取的是搜索结果页上的「Cited by」数字。Google 可能会要求人机验证或限流，这时会跳过它并使用下一个来源；读取过于频繁更容易被拦，因此请不要把刷新间隔调得太小。 「自动」按来源覆盖范围排序：Google Scholar 收录最广，OpenAlex 次之且文档公开，Semantic Scholar 覆盖的期刊最少。某个来源没有数据（或本次被限流）时会自动顺延到下一个；列里悬停会显示当前数字的来源。 Semantic Scholar 未提供 key 时会限流，遇到 429 会跳过并保留下次机会。 右键任意条目选择「刷新 alphaXiv 点赞」可以重新读取；缓存也可以按时间自动过期。 把列聚焦在一段点赞区间内；边界为 0 表示不限制。范围之外的条目仍然显示，只是整格变淡。
